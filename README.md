# 🌐 Web Development Internship – Week 4

This repository contains my Week 4 work completed as part of the **Web Development Internship**.

Week 4 focused on advanced JavaScript concepts including **Local Storage, JSON, API Fetch, Form Validation, ES6 features, DOM manipulation, and front-end project integration**.

---

## 📚 Week 4 Practice Tasks

### 1️⃣ Local Storage

A simple web page that stores a user's name using the browser's Local Storage.

**Features:**
- Accepts user's name
- Stores the name using `localStorage`
- Displays a welcome message after page reload

**Technologies:**
- HTML
- JavaScript
- Local Storage

---

### 2️⃣ Email Validation

A JavaScript-based email validation practice project.

**Features:**
- Accepts an email address
- Validates the entered email using JavaScript
- Displays whether the email is valid or invalid

**Technologies:**
- HTML
- JavaScript
- Regular Expressions

---

### 3️⃣ API Fetch – Random Quote

A simple project that retrieves a random quote from an online API.

**Features:**
- Fetches quote data using the Fetch API
- Processes JSON response data
- Displays the quote and author
- Includes basic error handling

**Technologies:**
- HTML
- JavaScript
- Fetch API
- JSON

---

### 4️⃣ Arrow Functions

A JavaScript practice project demonstrating the use of ES6 arrow functions.

**Features:**
- Uses an array of numbers
- Filters numbers greater than 50
- Uses an arrow function with `filter()`
- Displays the filtered results

**Technologies:**
- HTML
- JavaScript
- ES6 Arrow Functions
- Array Methods

# 🛍️ Major Project – VÉLORA

## Shop. Discover. Enjoy.

**VÉLORA** is a modern front-end e-commerce website developed as the Week 4 capstone project.

The project demonstrates the integration of HTML, CSS and JavaScript into a complete interactive shopping interface.

---

## ✨ Features

### 🏠 Home Page
- Premium hero section
- New collection presentation
- Shop Now navigation

### 🔍 Product Search
- Search products by name
- Dynamic product filtering

### 🏷️ Category Filtering
Products can be filtered by:

- All
- Electronics
- Fashion
- Home
- Accessories

### 📦 Product Cards
Each product displays:

- Product name
- Category
- Price
- Original price
- Discount percentage
- Rating
- Product visual

### 👀 Product Details
Clicking a product opens a detailed product popup containing:

- Product information
- Description
- Price
- Rating
- Add to Cart option

### 🛒 Shopping Cart
The cart supports:

- Adding products
- Removing products
- Cart item count
- Automatic total calculation
- Persistent cart data using Local Storage

### 💳 Checkout
A demonstration checkout function is included for the front-end project.

### 📱 Responsive Design
The website is designed to work across:

- Desktop
- Tablet
- Mobile devices

---

## 🧰 Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Local Storage
- Fetch API
- JSON
- ES6
- Responsive Web Design
